# 【重要】本前端工程不再上传云函数

请先看这一条：

本前端工程不再作为正式云函数上传源。

唯一正式云端源是：

`农鲜通后台管理平台/uniCloud-aliyun`

## 必须记住

1. 正式云函数统一从 `农鲜通后台管理平台/uniCloud-aliyun` 上传。
2. 正式 common 也统一从 `农鲜通后台管理平台/uniCloud-aliyun` 上传。
3. 本前端工程里的重复云函数、重复 common、重复上传源已经删除。
4. 以后如果要修改云函数，必须去后端平台工程修改。
5. 不要在本前端工程新建并上传同名云函数。

## 为什么要这样做

如果误在前端工程上传同名云函数或 common，会直接覆盖后端正式版本，导致线上功能异常。

这是禁止操作。

## 前端现在负责什么

前端只负责：

- 页面
- 组件
- 调用已部署云函数的代码

前端不再负责：

- 上传正式云函数
- 上传正式 common
- 维护正式云端源
