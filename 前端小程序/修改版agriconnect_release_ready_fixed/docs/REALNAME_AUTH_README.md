# 实名认证云函数说明

本文件已收口更新。

## 重要结论

实名认证相关正式云函数不再从本前端工程上传。

正式上传源统一为：

`农鲜通后台管理平台/uniCloud-aliyun`

## 当前正确做法

1. 前端页面继续调用同一服务空间中已经部署的正式函数。
2. 需要修改 `getRealnameAuthStatus`、`submitRealnameAuth` 等云函数时，去后端平台工程修改。
3. 需要上传部署时，也只在后端平台工程操作。

## 明确禁止

- 不要在本前端工程恢复实名认证云函数目录
- 不要在本前端工程上传实名认证相关云函数
- 不要在本前端工程恢复任何会参与上传的 common

## 风险提示

如果误把前端工程中的同名云函数或 common 上传到服务空间，会覆盖后端正式版本，导致线上异常。
