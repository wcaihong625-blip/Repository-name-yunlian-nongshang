# 微信登录云函数说明

本文件已更新为收口版本。

## 重要结论

`wechatLogin`、`bindPhoneNumber` 等正式云函数，不再从本前端工程上传。

正式上传源统一为：

`农鲜通后台管理平台/uniCloud-aliyun`

## 正确操作

1. 需要修改微信登录云函数时，去后端平台工程修改。
2. 需要上传部署时，也只在后端平台工程操作。
3. 前端页面继续调用同一服务空间里已经部署的正式函数。

## 禁止操作

- 不要在本前端工程新建 `wechatLogin`
- 不要在本前端工程新建 `bindPhoneNumber`
- 不要在本前端工程恢复 `uni-config-center` 或其它 common 上传源

## 风险提示

如果在前端工程误上传同名云函数或 common，会直接覆盖后端正式版本，属于禁止操作。
