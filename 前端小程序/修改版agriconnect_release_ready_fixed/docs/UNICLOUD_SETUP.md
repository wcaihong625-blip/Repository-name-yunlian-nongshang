# uniCloud 使用说明

## 重要结论

本前端工程不再作为正式云函数上传源。

正式云函数、正式 common、正式配置，统一以：

`农鲜通后台管理平台/uniCloud-aliyun`

为唯一正式上传源。

## 现在该怎么做

1. 前端页面仍然可以正常调用同一服务空间中已经上传好的正式云函数。
2. 如需修改云函数，请到 `农鲜通后台管理平台/uniCloud-aliyun` 修改。
3. 不要在本前端工程恢复、创建、上传任何同名云函数或 common。

## 明确禁止

- 禁止在本前端工程上传云函数
- 禁止在本前端工程上传 common
- 禁止把本前端工程当成正式 uniCloud 源

## 原因

如果误把前端工程中的同名云函数或 common 上传到服务空间，会覆盖后端正式版本，造成线上功能异常。
