# 部署说明

本文件已收口更新。

## 重要结论

本前端工程不再承担任何正式云函数、common、云端配置的上传职责。

唯一正式云端源为：

`农鲜通后台管理平台/uniCloud-aliyun`

## 当前正确做法

1. 前端只保留页面、组件、调用代码。
2. 正式云函数修改、common 修改、正式上传部署，统一在 `农鲜通后台管理平台/uniCloud-aliyun` 完成。
3. 前端如果需要调用云函数，继续按原方式调用已部署到同一服务空间的正式函数即可。

## 明确禁止

- 不要在本前端工程上传云函数
- 不要在本前端工程上传 common
- 不要在本前端工程恢复任何同名云函数目录

## 风险提示

如果误把前端工程里的同名云函数或 common 上传到服务空间，会覆盖后端正式版本，导致线上功能异常。
