# 微信登录说明

本文件已收口更新。

## 重要结论

本前端工程不再作为微信登录云函数的正式上传源。

正式云函数、正式 common、正式配置统一位于：

`农鲜通后台管理平台/uniCloud-aliyun`

## 正确操作

1. 需要修改 `wechatLogin`、`bindPhoneNumber`、登录配置时，去后端平台工程处理。
2. 需要上传部署时，也只在后端平台工程操作。
3. 前端页面继续调用同一服务空间里已部署的正式云函数。

## 明确禁止

- 不要在本前端工程新建或恢复登录云函数目录
- 不要在本前端工程恢复 `common/uni-config-center`
- 不要在本前端工程上传任何同名云函数或 common

## 风险提示

如果误把前端工程中的同名云函数或 common 上传到服务空间，会直接覆盖后端正式版本，属于禁止操作。
