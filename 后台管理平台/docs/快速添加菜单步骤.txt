========================================
快速添加订单管理菜单步骤
========================================

方法一：通过后台菜单管理页面添加（推荐）

步骤1：登录后台管理系统

步骤2：进入菜单管理
  左侧菜单 → 系统管理 → 菜单管理
  或直接访问：/pages/system/menu/list

步骤3：添加主菜单"订单管理"
  点击"新增菜单"按钮，填写：
  ┌─────────────────────────────────┐
  │ 菜单ID: order_management         │
  │ 菜单名称: 订单管理               │
  │ 图标: uni-icons-cart (可选)     │
  │ URL: (留空)                      │
  │ 排序: 3000                       │
  │ 父级菜单: (留空)                 │
  │ 是否启用: 是                     │
  └─────────────────────────────────┘
  点击保存

步骤4：添加4个子菜单

  子菜单1 - 开店付费订单：
  ┌─────────────────────────────────┐
  │ 菜单ID: order_management_shop_payment │
  │ 菜单名称: 开店付费订单           │
  │ URL: /pages/shop_payment_orders/list │
  │ 排序: 3010                       │
  │ 父级菜单: 订单管理               │
  │ 是否启用: 是                     │
  └─────────────────────────────────┘

  子菜单2 - 支付状态跟踪：
  ┌─────────────────────────────────┐
  │ 菜单ID: order_management_payment_status │
  │ 菜单名称: 支付状态跟踪           │
  │ URL: /pages/payment_status_tracking/list │
  │ 排序: 3020                       │
  │ 父级菜单: 订单管理               │
  │ 是否启用: 是                     │
  └─────────────────────────────────┘

  子菜单3 - 退款申请处理：
  ┌─────────────────────────────────┐
  │ 菜单ID: order_management_refund  │
  │ 菜单名称: 退款申请处理           │
  │ URL: /pages/refund_applications/list │
  │ 排序: 3030                       │
  │ 父级菜单: 订单管理               │
  │ 是否启用: 是                     │
  └─────────────────────────────────┘

  子菜单4 - 交易纠纷调解：
  ┌─────────────────────────────────┐
  │ 菜单ID: order_management_dispute │
  │ 菜单名称: 交易纠纷调解           │
  │ URL: /pages/transaction_disputes/list │
  │ 排序: 3040                       │
  │ 父级菜单: 订单管理               │
  │ 是否启用: 是                     │
  └─────────────────────────────────┘

步骤5：刷新页面
  添加完成后，按 F5 刷新浏览器
  左侧菜单栏应该可以看到"订单管理"菜单

========================================
注意事项
========================================

1. 必须先添加父菜单（订单管理），再添加子菜单
2. 父级菜单字段必须选择正确的父菜单名称
3. URL路径要与pages.json中的路由配置一致
4. 确保所有菜单的"是否启用"选项都是"是"
5. 如果菜单不显示，尝试刷新浏览器或重新登录

========================================
如果菜单还是不显示？
========================================

1. 检查菜单管理页面，确认菜单已成功添加且启用
2. 检查URL路径是否正确（与pages.json中的路径一致）
3. 刷新浏览器（F5或Ctrl+R）
4. 清除浏览器缓存后重新登录
5. 检查浏览器控制台是否有错误信息（F12）
