## 功能说明

### 1. 开店付费订单 (shop_payment_orders)
- 管理店铺开通时产生的付费订单
- 支持订单号、店铺、用户、金额、支付方式等字段
- 订单状态：待支付、已支付、已取消、已退款

### 2. 支付状态跟踪 (payment_status_tracking)
- 跟踪各类订单的支付状态变化
- 记录状态历史记录
- 监控支付回调状态

### 3. 退款申请处理 (refund_applications)
- 处理用户退款申请
- 支持审核流程（待审核、审核通过、审核拒绝等）
- 记录退款金额、原因、方式等信息

### 4. 交易纠纷调解 (transaction_disputes)
- 处理买卖双方的交易纠纷
- 支持上传证据图片
- 记录调解过程和结果

## 使用建议

1. **数据库初始化：** 首先需要在uniCloud控制台初始化数据库schema
2. **页面完善：** 根据业务需求完善列表页和编辑页的功能
3. **权限控制：** 可以在菜单配置中添加权限控制
4. **业务逻辑：** 根据实际业务需求添加相应的云函数逻辑

## 注意事项

- 所有时间字段使用timestamp类型
- 金额字段使用number类型
- 状态字段建议使用枚举值
- 列表页面支持筛选、排序、分页等功能
- 编辑页面需要根据业务需求添加相应的表单验证
